This folder contains BUSCO assessments of the genomes that were used to generate the 37 species-specific chloroplast models. Because we were unable to run a full BUSCO workflow with the recent versions of BUSCO and its dependencies, we employed custom compatibility fixes that are published on [GitHub](https://github.com/emilpaulitz/busco-apptainer). The specific version used was archived using Zenodo: https://doi.org/10.5281/zenodo.23503216
